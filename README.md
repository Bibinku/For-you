# For You
```
npm install
npm run dev     # open the printed URL on your phone (same Wi-Fi)
npm run build   # deploy /dist to Netlify / Vercel / GitHub Pages
```
Edit `src/content.js` for names, dates, messages and photos. Put photos in `public/photos/` and use `"/photos/1.jpg"`.
Reorder or add pages in the `pages` array in `src/App.jsx`.
